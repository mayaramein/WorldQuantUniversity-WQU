# Project One

Project Overview
This project introduces learners to the fundamental building blocks of deep learning using PyTorch. Students begin by manipulating tensors and understanding real-world data representations. From there, they progressively build models, starting with linear regression and culminating in a simple multi-layer neural network (MLP). Using the Concrete Compressive Strength dataset, learners explore the relationship between model complexity, non-linearity, and prediction performance.

Some of the things you'll learn are:

Understanding the conceptual underpinnings of deep learning and its historical context
Working with real datasets and represent them as PyTorch tensors
Implementing linear regression and understand gradient descent training
Introducing and visualizing activation functions like ReLU and Sigmoid
Building and training a basic MLP using PyTorch modules
Analyzing underfitting and overfitting in neural networks
